Sistema atualizado

Atualiza os programas instalados e liga as atualizações automáticas de segurança.

Em resumo

O que faz e o que não faz

✓O que faz

  • Atualiza a lista de pacotes e todos os programas instalados pelo apt.
  • Instala dependências novas que uma atualização pedir, como um kernel novo.
  • Termina instalações que ficaram pela metade, com dpkg --configure -a.
  • Liga as atualizações automáticas de segurança, que passam a ser instaladas sozinhas todo dia.
  • Avisa quando é preciso reiniciar para usar o kernel novo.

✕O que não faz

  • Não remove nenhum pacote. Remoções ficam para você decidir.
  • Não troca a versão da distro, por exemplo do Ubuntu 24.04 para o 26.04.
  • Não atualiza aplicativos Flatpak ou Snap; só os pacotes do apt.
  • Não reinicia o computador por você.
  • Não volta versões ao desfazer: o apt não sabe fazer isso. Para isso existe o snapshot.

Passo a passo

Como o bora aplica esta receita

Toda receita passa pelas mesmas quatro etapas. Esta é a sequência exata, com o que cada uma confere.

  1. Verificar já está aplicada?

    Antes de mudar qualquer coisa, o bora pergunta à receita se há algo a fazer. Ela responde que sim se:

    • a lista de pacotes não foi atualizada nas últimas 6 horas;
    • há pacotes instalados pela metade;
    • a simulação apt-get -s upgrade mostra pacotes para atualizar;
    • as atualizações automáticas estão desligadas.

    Se nada disso acontece, o bora pula a receita e diz que ela já estava aplicada.

  2. Aplicar faz a mudança

    • Roda dpkg --configure -a se algo ficou pela metade.
    • Roda apt-get update e apt-get upgrade --with-new-pkgs.
    • Instala o unattended-upgrades, se ainda não estiver instalado.
    • Liga as duas opções em /etc/apt/apt.conf.d/20auto-upgrades, só se elas ainda não estiverem ligadas.
    • Habilita os timers apt-daily.timer e apt-daily-upgrade.timer.

    No Ubuntu, quase tudo isso já vem ligado; aí a receita só atualiza os pacotes.

  3. Testar funcionou?

    A receita confere quatro coisas e imprime cada uma: nenhum pacote pela metade, nenhum pacote para atualizar, o unattended-upgrades instalado e as duas opções valendo 1. Pacotes retidos de propósito pela distro, como as atualizações em fases do Ubuntu, não contam.

  4. Desfazer quando você pedir

    Volta o 20auto-upgrades ao que era, desabilita os timers que a receita habilitou e remove o unattended-upgrades, se foi ela que instalou. As versões novas dos pacotes ficam: para voltar a elas, use o snapshot criado antes do plano.

Os porquês

Por que assim

Por que atualizar antes de tudo?

A maioria dos problemas de segurança é corrigida por atualizações que já existem, mas ainda não foram instaladas. E um computador recém-instalado costuma estar semanas atrás, porque a imagem de instalação foi gerada antes.

Por que --with-new-pkgs?

O upgrade comum deixa de lado as atualizações que pedem um pacote novo, como um kernel novo. Com essa opção, elas entram. E, diferente do dist-upgrade, ela nunca remove pacotes.

O que as atualizações automáticas instalam?

Só o que vem dos repositórios de segurança da distro. Elas não trocam a versão da distro e não instalam programas novos, então o computador não muda de cara de um dia para o outro.

Por que o desfazer não volta as versões?

O apt não guarda as versões antigas dos pacotes, e voltar uma versão de segurança deixaria o computador vulnerável de novo. Se uma atualização trouxer problema, o snapshot volta o sistema inteiro.

Como

O que muda no sistema

  • Pacotes atualizadosTodos os que o apt tiver para atualizar, mais as dependências novas. Nenhum é removido.
  • unattended-upgradesInstalado só se ainda não estiver. É ele que instala as atualizações de segurança sozinho.
  • /etc/apt/apt.conf.d/20auto-upgradesLiga APT::Periodic::Update-Package-Lists e APT::Periodic::Unattended-Upgrade, se ainda não estiverem ligadas.
  • apt-daily.timer e apt-daily-upgrade.timerOs agendamentos do systemd que buscam e instalam as atualizações. Se um estiver mascarado, a receita só avisa.

Os comandos que o teste roda

Rode no terminal para ver com os próprios olhos. Nenhum deles muda nada.

dpkg --auditLista pacotes instalados pela metade. Não pode mostrar nada.
apt-get -s upgrade --with-new-pkgsSimula a atualização. Não pode sobrar nenhum pacote para atualizar.
apt-config dump | grep PeriodicMostra as opções das atualizações automáticas. As duas precisam valer "1".
systemctl list-timers 'apt-daily*'Mostra quando as atualizações vão rodar de novo.
ls /var/run/reboot-requiredSe o arquivo existir, reinicie quando puder para usar o kernel novo.
