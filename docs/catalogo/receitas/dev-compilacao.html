Ferramentas de compilação

Instala o compilador de C e C++, o make e o pkg-config, que muitos pacotes de Python e de Node.js pedem na instalação.

dev/compilacao Risco baixo Pede a senha de administrador Testada no Ubuntu e no Debian

Em resumo

O que faz e o que não faz

✓O que faz

  • Instala o compilador de C e de C++, o gcc e o g++.
  • Instala o make e as bibliotecas básicas do C, pelo build-essential.
  • Instala o pkg-config, que os scripts de compilação usam para achar as bibliotecas do sistema.

✕O que não faz

  • Não configura nada: são só programas novos.
  • Não instala bibliotecas de projetos específicos, como as de banco de dados ou de imagem.
  • Não remove no desfazer o que outro programa passou a usar.

Passo a passo

Como o bora aplica esta receita

As mesmas quatro etapas de toda receita, com o que esta confere em cada uma.

  1. Verificar já está aplicada?

    Confere se os pacotes build-essential e pkg-config estão instalados.

  2. Aplicar faz a mudança

    Instala os dois, com as dependências que faltarem, e anota tudo o que entrou.

  3. Testar funcionou?

    Roda gcc, g++, make e pkg-config, e compila e roda um programa de uma linha em C e outro em C++, numa pasta temporária.

  4. Desfazer quando você pedir

    Remove os pacotes que a receita instalou, com as dependências que vieram junto, menos o que outro programa passou a usar.

Os porquês

Por que assim

Por que, se eu vou programar em Python ou JavaScript?

Muitos pacotes do pip e do npm têm um pedaço em C ou C++, por velocidade. Quando não há uma versão pronta para a sua máquina, eles são compilados na hora da instalação. Sem o compilador, o erro aparece no meio de um monte de texto em inglês.

O que é o build-essential?

Um pacote que não tem nada dentro: ele só puxa o gcc, o g++, o make e as bibliotecas do C. É o jeito que o Debian e o Ubuntu fazem para instalar o kit básico de uma vez.

Como

O que muda no sistema

  • build-essentialO gcc, o g++, o make e as bibliotecas básicas do C.
  • pkg-configAcha as bibliotecas instaladas para os scripts de compilação.

Parâmetros

O que dá para escolher

Esta receita não tem parâmetros: ela faz sempre a mesma coisa, em qualquer máquina. No menu, o bora não pergunta nada; num script ou num agente, basta bora plano --receitas dev/compilacao.
