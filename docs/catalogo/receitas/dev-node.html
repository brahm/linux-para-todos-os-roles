Node.js

Instala o Node.js LTS oficial, com o npm instalando pacotes globais na sua pasta pessoal, sem sudo.

Em resumo

O que faz e o que não faz

✓O que faz

  • Instala o Node.js LTS oficial, com o npm e o npx, igual em todas as distros.
  • Confere a soma SHA256 do arquivo baixado antes de instalar.
  • Faz o npm install -g funcionar sem sudo, instalando na sua pasta pessoal.
  • Cria a pasta ~/.local/bin, onde aparecem os comandos instalados pelo npm.

✕O que não faz

  • Não usa o Node.js da distro, que no Ubuntu 24.04 é a versão 18, já fora de suporte.
  • Não remove o Node.js da distro, se ele estiver instalado: só passa na frente no PATH.
  • Não atualiza sozinho pelo apt: a versão sobe com o bora.
  • Não passa por cima de um node que você instalou à mão em /usr/local/bin.
  • Não apaga os pacotes que você instalou com npm install -g no desfazer.

Passo a passo

Como o bora aplica esta receita

As mesmas quatro etapas de toda receita, com o que esta confere em cada uma.

  1. Verificar já está aplicada?

    Confere se o Node.js da versão da receita está em /usr/local/lib/nodejs, se node, npm e npx em /usr/local/bin apontam para ele, se o npmrc está como a receita escreve e se ~/.local/bin existe.

  2. Aplicar faz a mudança

    • Para, sem mudar nada, se já houver um node em /usr/local/bin que não veio do bora.
    • Baixa o arquivo de nodejs.org, confere a soma SHA256 gravada na receita e abre em /usr/local/lib/nodejs.
    • Cria os links em /usr/local/bin, escreve prefix=${HOME}/.local no npmrc do Node.js e cria ~/.local/bin.

  3. Testar funcionou?

    Como a pessoa: confere a versão do node, o npm e o npx, roda um programa e confere que o npm prefix -g é ~/.local.

  4. Desfazer quando você pedir

    Apaga os links e a pasta do Node.js, remove os pacotes que a receita instalou e a pasta ~/.local/bin, se ainda estiver vazia.

Os porquês

Por que assim

Por que não o Node.js da distro?

No Ubuntu 24.04 e nas derivadas, como o Linux Mint 22, o Pop!_OS e o Zorin OS, ele é a versão 18, que saiu de suporte em 2025. As ferramentas de hoje, como o Vite, pedem uma versão mais nova, e o primeiro tutorial já quebraria.

É seguro baixar de fora da distro?

O arquivo vem de nodejs.org, do próprio projeto, e a receita traz a soma SHA256 do arquivo que foi testado. Se o que chegar não bater, nada é instalado. É a regra do projeto para instaladores oficiais.

Por que o npm sem sudo?

Com sudo npm install -g, os arquivos ficam do root, e o próximo npm sem sudo falha com EACCES. Daí para o chmod 777 é um passo, e ninguém quer dar esse passo. Com o prefix em ~/.local, cada pessoa instala na própria pasta.

Como atualizar?

Quando sair um bora com uma versão nova do Node.js, aplique a receita de novo. Ela instala a nova ao lado e troca os links.

Como

O que muda no sistema

  • curl, xz-utils e ca-certificatesPara baixar e abrir o arquivo, se faltarem.
  • /usr/local/lib/nodejs/node-v26.13.0-linux-x64O Node.js, com o npm e o npx, e o etc/npmrc com o prefix.
  • /usr/local/bin/node, npm e npxLinks para a versão instalada.
  • ~/.local/binCriada vazia, se ainda não existir. Entra no PATH no próximo login.

Parâmetros

O que dá para escolher

ParâmetroPadrãoO que é
usuarioautoA conta que vai programar, para a pasta ~/.local/bin, onde o npm põe os programas instalados com -g. "auto" é quem rodou o bora com sudo.

No menu, o bora pergunta o que precisa. Num script ou num agente, passe os parâmetros na linha de comando:
bora plano --receitas dev/node -p dev/node.usuario=auto
