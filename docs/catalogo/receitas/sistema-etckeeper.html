Histórico do /etc

Guarda cada mudança na configuração do sistema (a pasta /etc) num histórico do Git, para ver o que mudou, quando e voltar um arquivo.

Em resumo

O que faz e o que não faz

✓O que faz

  • Guarda a pasta /etc num repositório do Git, com o primeiro registro na hora.
  • Registra cada instalação do apt, antes e depois, e o que mudou por fora dele uma vez por dia.
  • Fecha o histórico com permissão só do root, porque o /etc tem as senhas cifradas.

✕O que não faz

  • Não manda o histórico para lugar nenhum: ele fica no próprio computador.
  • Não substitui o snapshot nem o backup: guarda só a configuração.
  • Não mexe num histórico do /etc que já existia antes do bora.

Passo a passo

Como o bora aplica esta receita

As mesmas quatro etapas de toda receita, com o que esta confere em cada uma.

  1. Verificar já está aplicada?

    Confere se o pacote etckeeper está instalado e se o /etc tem um histórico com pelo menos um registro.

  2. Aplicar faz a mudança

    Instala o etckeeper, que cria o histórico e o primeiro registro, registra o que tiver mudado desde então e fecha a pasta /etc/.git para o root.

  3. Testar funcionou?

    Confere o histórico, o gancho do apt, a permissão 700 de /etc/.git e o arquivo onde ficam o dono e as permissões de cada arquivo.

  4. Desfazer quando você pedir

    Guarda uma cópia do histórico em /var/backups, remove o repositório com etckeeper uninit e tira o pacote. Os arquivos do /etc ficam como estão.

No terminal

Uma aplicação de verdade

A saída de um teste no Ubuntu 24.04, encurtada nas linhas do apt.

Os porquês

Por que assim

Já tenho o snapshot. Para que outro?

O snapshot volta o sistema inteiro a como estava ontem. O histórico do /etc responde a uma pergunta menor: o que mudou na configuração desde que o Wi-Fi parou? Com ele, dá para ver a diferença de um arquivo e voltar só aquele, sem desfazer o resto.

Por que o Git?

É a ferramenta que todo mundo que programa usa para guardar versões, e o git log -p mostra, linha por linha, o que cada programa e cada receita do bora mudou. Para quem está aprendendo, é um jeito de ver o sistema por dentro.

Como

O que muda no sistema

  • etckeeperGuarda o /etc no Git e avisa o apt antes e depois de cada instalação. Traz o git, se faltar.
  • /etc/.git e /etc/.etckeeperO histórico, com permissão só do root, e o dono e as permissões de cada arquivo.
  • etckeeper.timerUm registro por dia do que mudou por fora do apt.

Parâmetros

O que dá para escolher

Esta receita não tem parâmetros: ela faz sempre a mesma coisa, em qualquer máquina. No menu, o bora não pergunta nada; num script ou num agente, basta bora plano --receitas sistema/etckeeper.

Confira você mesmo

Os comandos para conferir

sudo git -C /etc log --onelineA lista de registros, do mais novo para o mais velho.
sudo git -C /etc log -p -- fstabO histórico de um arquivo, com as linhas que mudaram.
sudo git -C /etc diffO que mudou desde o último registro.
