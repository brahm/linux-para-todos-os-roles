Ferramentas do terminal

Instala o ripgrep, o fd, o jq e o GitHub CLI, que os agentes de IA e quem programa usam o tempo todo.

Em resumo

O que faz e o que não faz

✓O que faz

  • Instala o ripgrep, o comando rg, que procura um texto em todos os arquivos de um projeto.
  • Instala o fd, que acha arquivos pelo nome, e cria o comando fd, que no Debian se chama fdfind.
  • Instala o jq, que lê e filtra JSON.
  • Instala o GitHub CLI, o gh, para clonar, abrir pull requests e entrar no GitHub pelo terminal.

✕O que não faz

  • Não entra no GitHub por você: o gh auth login é seu.
  • Não passa por cima de um fd que já exista em /usr/local/bin.
  • Não vem de fora da distro: os quatro estão nos repositórios do Ubuntu e do Debian.

Passo a passo

Como o bora aplica esta receita

As mesmas quatro etapas de toda receita, com o que esta confere em cada uma.

  1. Verificar já está aplicada?

    Confere se os pacotes ripgrep, fd-find, jq e gh estão instalados e se existe o comando fd.

  2. Aplicar faz a mudança

    Instala os pacotes que faltarem e cria o link /usr/local/bin/fd para o fdfind.

  3. Testar funcionou?

    Numa pasta de teste, procura um texto com rg, acha um arquivo com fd, lê um JSON com jq e roda gh --version.

  4. Desfazer quando você pedir

    Apaga o link do fd e remove os pacotes que a receita instalou, menos o que outro programa passou a usar.

Os porquês

Por que assim

Por que o agente precisa delas?

Para entender um projeto, o agente procura textos e arquivos o tempo todo. O rg é muito mais rápido que o grep -r e pula o que está no .gitignore, como a pasta node_modules. Vários agentes procuram o rg primeiro.

Por que o fd se chama fdfind?

No Debian, já existia outro programa com o nome fd. O pacote usa fdfind, e a receita cria o nome curto, que é o que os tutoriais e os agentes usam.

Como

O que muda no sistema

  • ripgrep, fd-find, jq e ghDos repositórios da distro.
  • /usr/local/bin/fdLink para /usr/bin/fdfind.

Parâmetros

O que dá para escolher

Esta receita não tem parâmetros: ela faz sempre a mesma coisa, em qualquer máquina. No menu, o bora não pergunta nada; num script ou num agente, basta bora plano --receitas dev/ferramentas.
