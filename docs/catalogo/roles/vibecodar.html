Em resumo

O que faz e o que não faz

Todas as receitas deste rolê existem, e ele já aparece no menu do bora. Toda semana, cada receita é aplicada, conferida e desfeita em máquinas virtuais de verdade, no Ubuntu 24.04, no Ubuntu 26.04 e no Debian 13, inclusive com a tela de login e o navegador; o registro de testes de cada receita mostra a última vez. Cada receita sabe se desfazer e, com o snapshot do sistema configurado, o bora tira um antes de aplicar.

✓O que o rolê faz

  • Tudo do “Começar a programar”, com o Python e o Node.js juntos, mais o ripgrep, o fd, o jq e o GitHub CLI, que os agentes usam o tempo todo.
  • Instala os agentes que você escolher (Claude Code, Codex, Copilot CLI, OpenCode e Mistral Vibe) na sua conta, sem sudo, pelos pacotes oficiais de cada fabricante.
  • Ensina o bora aos agentes, com uma skill que mostra como montar um plano e pedir para você aplicar.
  • Guarda as chaves de API num arquivo em ~/.config que só você lê, carregado em cada terminal.
  • Confere cada commit com o gitleaks, e o Git passa a ignorar os arquivos .env em todos os projetos.
  • Coloca os agentes numa caixa de areia, se você quiser, onde eles só escrevem na pasta do projeto e não veem as suas chaves SSH.
  • Instala o editor que você escolher: VS Code, VSCodium, Zed ou só o terminal.

✕O que ele não faz

  • Nenhum agente recebe sudo. Quem aplica mudanças no sistema é sempre você, pelo bora.
  • Não pergunta nem guarda a sua chave de API no plano: você cola a chave no arquivo, depois.
  • Não assina planos pagos nem cria contas por você.
  • Ainda não traz o Antigravity CLI, que só tem instalador do tipo curl | sh, nem o Ollama, para modelos locais.
  • Não esconde que este é o rolê que mais quebra: os agentes mudam toda semana, e a máquina virtual do CI confere todos toda semana.

Passo a passo

Como o bora leva você até lá

  1. Escolha o rolê no menu

    Rode sudo bora no terminal. O menu mostra só os rolês que cabem na sua máquina e na sua distro, e você escolhe pelo número.

  2. Responda o que for preciso em português

    Para este rolê, o bora pergunta:

    • Quais agentes você quer: Claude Code, Codex, Copilot CLI, OpenCode ou Mistral Vibe? (o padrão é o OpenCode)
    • Vai usar chave de API: OpenRouter, DeepSeek ou outra? (o padrão é não)
    • Qual editor: VS Code, VSCodium, Zed ou só o terminal? (o padrão é o terminal)
    • Quer rodar os agentes numa caixa de areia? (o padrão é sim)
    • Que e-mail vai nos seus commits? Use o mesmo da sua conta no GitHub ou no GitLab.

  3. Revise o plano nada mudou ainda

    O bora mostra o plano: as receitas, na ordem, com os parâmetros. Você pode aplicar agora, só simular, ou salvar o plano para revisar com calma, versionar ou aplicar em outra máquina.

  4. Snapshot antes de mudar o ponto de volta

    Se o snapshot do sistema já estiver configurado, o bora tira uma foto do sistema antes da primeira mudança. Se o próprio rolê configura o snapshot, as próximas mudanças já ganham o ponto de volta.

  5. Uma receita de cada vez verificar, aplicar, testar

    Cada receita primeiro verifica se já está aplicada, e pula se estiver. Depois aplica e testa. Se uma falhar, o bora para ali, diz o que aconteceu e como voltar. As 13 receitas deste rolê estão logo abaixo.

  6. Pronto quando o teste que qualquer pessoa faz

    Cada agente responde no terminal (na primeira vez, ele pede para entrar na sua conta), e um projeto de exemplo é criado, versionado e tem o commit barrado pelo gitleaks quando leva uma chave.

  7. Para voltar atrás sudo bora desfazer

    O bora remove os agentes, o editor, o gitleaks e a caixa de areia que instalou, e volta o Git e o .bashrc ao que eram. Os seus projetos, a chave SSH, os logins dos agentes e o arquivo de chaves, se você colou alguma, ficam onde estão.

Os porquês

Por que assim

Por que caixa de areia?

Um agente roda comandos no seu computador. Na caixa, um comando errado, ou uma instrução escondida num arquivo do projeto, estraga no máximo a pasta do projeto, que está no Git.

Por que o gitleaks?

Colar uma chave de API num arquivo e fazer commit é o acidente mais comum de quem começa com agentes. O gitleaks barra o commit antes.

Por que qualquer agente serve?

O rolê não depende de um fornecedor. O OpenCode funciona com modelos gratuitos, o Codex com a conta gratuita do ChatGPT e o Copilot CLI com o plano gratuito do Copilot.

Por que os agentes na minha conta?

Assim eles nunca rodam como root e se atualizam sozinhos, sem sudo. É também o que deixa a caixa de areia fazer sentido.
