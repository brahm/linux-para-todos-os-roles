Qual distro combina com você?

Vai usar o bora agora? Fique com o Ubuntu, o Debian ou uma derivada do Ubuntu (Mint, Zorin, Pop!_OS): são as famílias da onda 1. Fedora, Bazzite e CachyOS são ótimas escolhas, mas o bora só chega nelas nas próximas ondas. Máquinas de 32 bits ficam de fora: nenhuma destas distros instala nelas.

Passos 2 e 3

Do pendrive ao primeiro boot

O caminho é o mesmo em todas as distros da lista. Os detalhes de cada tela estão no guia oficial de cada uma; aqui fica o mapa e o que costuma dar errado.

  1. 1

    Guarde o que importa antes de tudo

    A instalação limpa apaga o disco inteiro, com o Windows e os arquivos. Copie fotos, documentos e senhas salvas no navegador para um disco externo ou para a nuvem, e confira se a cópia abre.

    • Instalar ao lado do Windows (dual boot) fica para a versão 2 do projeto: BitLocker, Secure Boot e partições variam demais, e o erro custa dados.
    • Confira se o computador é de 64 bits. No Windows: Configurações › Sistema › Sobre, em “Tipo de sistema”.
  2. 2

    Baixe a imagem e confira uns 3 a 8 GB

    A imagem é um arquivo .iso. Baixe só do site oficial (os links estão nos cartões acima) e compare o código de conferência, o SHA256, com o que o site mostra. Se for diferente, o download veio quebrado ou adulterado: baixe de novo.

    • Get-FileHash arquivo.isono PowerShell do Windows
    • shasum -a 256 arquivo.isono Terminal do macOS
    • sha256sum arquivo.isonum Linux
  3. 3

    Grave o pendrive 8 GB ou mais

    Tudo o que estiver no pendrive será apagado. Copiar o .iso para dentro dele não funciona: é preciso um programa que grave a imagem.

    • No Windows: Rufus, balenaEtcher ou o Fedora Media Writer.
    • No macOS: balenaEtcher ou Fedora Media Writer.
    • Num Linux: o Fedora Media Writer, ou o app Discos (GNOME), em “Restaurar imagem de disco”.
    • Quer testar várias? O Ventoy prepara o pendrive uma vez, e depois é só copiar quantas .iso couberem.
    • O Bazzite tem uma imagem grande: use um pendrive de 16 GB.
  4. 4

    Dê o boot pelo pendrive

    Com o pendrive espetado, ligue o computador apertando várias vezes a tecla do menu de boot e escolha o pendrive (às vezes aparece como “UEFI: nome do pendrive”). Se o Windows estiver funcionando, há um atalho: segure Shift, clique em Reiniciar e escolha “Usar um dispositivo”.

  5. 5

    Experimente antes de instalar nada é gravado no disco

    Quase todas abrem um modo “ao vivo”, rodando do pendrive. Aproveite para conferir o que mais dá problema: Wi-Fi, som, brilho da tela, touchpad e webcam. Se algo não funcionar, veja as armadilhas logo abaixo antes de seguir.

  6. 6

    Instale uns 15 a 30 minutos

    • Idioma: Português (Brasil). Teclado: “Português (Brasil)” se o teclado tem a tecla Ç; se não tem, “Inglês (EUA, internacional com teclas mortas)”.
    • Disco: “Apagar o disco e instalar”. Criptografar o disco protege seus dados se o notebook for roubado, mas sem a senha não há volta: anote.
    • Codecs e programas de terceiros: pode deixar desmarcado. O rolê Pronto para estudar e trabalhar instala os codecs depois, e sabe desfazer.
    • Usuário: um nome curto, sem acento nem espaço, e uma senha que você lembre. É ela que o sudo vai pedir.
  7. 7

    Primeiro boot

    Tire o pendrive quando o instalador pedir e reinicie. Não precisa sair instalando atualizações e programas: o próximo passo é conseguir internet e deixar o bora arrumar a casa.

Quando trava

Armadilhas comuns

O que mais dá errado na primeira instalação, e a saída para cada uma.

O computador ignora o pendrive

Grave de novo com outro programa, tente outra porta USB (as de trás, no desktop) e desligue o “Fast Boot” no setup. Ubuntu, Mint, Debian e Fedora dão boot com o Secure Boot ligado; as outras podem pedir para desligá-lo, e o guia oficial diz se é o caso.

O instalador não acha o disco

Muitos notebooks com Intel saem de fábrica com o disco em modo RST ou VMD. No setup, troque o modo do disco para AHCI, ou desligue o VMD. Numa instalação limpa isso não estraga nada.

Tela preta ou travada no boot

É quase sempre a placa de vídeo, em geral NVIDIA. No menu do pendrive, escolha “modo de compatibilidade” (Mint) ou “Safe graphics” (Ubuntu). Depois de instalar, o gerenciador de drivers resolve. O Pop!_OS tem uma imagem com o driver já dentro.

Sem Wi-Fi

Algumas placas Broadcom e Realtek precisam de um driver que só vem pela internet. Ligue por cabo ou pelo celular (veja abaixo) e abra o “Gerenciador de drivers” no Mint ou “Drivers adicionais” no Ubuntu.

O teclado não faz ç nem acento

O layout errado foi escolhido na instalação. Em Configurações › Teclado, troque para “Português (Brasil)” se houver a tecla Ç, ou “Inglês (EUA, internacional com teclas mortas)” se não houver.

Computador muito velho

Se ele for de 32 bits, de antes de 2008 mais ou menos, nenhuma distro desta página instala nele, e o projeto deixou esse caso de fora. Com 64 bits e 2 GB de memória, o Mint Xfce e o Debian com LXQt ainda dão conta.

Passo 4, primeiro pedaço

Conseguir internet

O bora baixa os programas da internet, então ela precisa estar funcionando.

1

Cabo

O caminho mais garantido: funciona sem driver e sem senha. Se o notebook não tem porta de rede, um adaptador USB para rede costuma funcionar direto.

2

Wi-Fi

Clique no ícone de rede, no canto da tela, escolha a rede e digite a senha. Se a lista de redes não aparece, é caso de driver: use o cabo ou o celular uma vez para instalá-lo.

3

Celular pelo USB

Ligue o Android no cabo USB e ative em Configurações › Rede e internet › Ponto de acesso › “Tethering USB” (o nome muda um pouco de marca para marca). Costuma funcionar sem instalar nada, mesmo quando o Wi-Fi do computador não funciona.

Passo 4

Instalar o bora e rodar bora diag

O bora é um arquivo só. Abra o Terminal (no Mint e no Ubuntu, Ctrl + Alt + T), baixe, confira e rode. O diag não muda nada: só mostra o que encontrou.

  • O OK do sha256sumGarante que o arquivo é o mesmo que saiu do projeto. Se aparecer outra coisa, apague e baixe de novo.
  • Processador ARM?O bora roda só em computadores de 64 bits com processador Intel ou AMD (x86_64).
  • Travou em algum ponto?Rode ./bora-linux-x86_64 ajuda: ele monta uma pergunta pronta, sem dados sensíveis, para colar em qualquer chat de IA.
